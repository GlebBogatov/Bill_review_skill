# Конфигурация

Пользовательские настройки скилла. **Отредактируй под свою среду перед первым
запуском.** Значения ниже — плейсхолдеры; подставь свои. Ключи соответствуют
плейсхолдерам из `SKILL.md`.

## Пути и окружение

| Ключ | Значение (заполни своим) |
|---|---|
| `<АРХИВ>` — корень архива | `<диск>:\<путь>\Чеки` |
| `<HOME>` — домашняя папка | `C:\Users\<Имя>` |
| `<PYTHON>` — интерпретатор | `C:\Users\<Имя>\AppData\Local\Programs\Python\Python3xx\python.exe` |
| `<TEMP>` — временные файлы | `C:\Users\<Имя>\AppData\Local\Temp\billrev` |
| Аккаунт Gmail (Gmail MCP) | подключённый read-only аккаунт |
| Chrome | `C:\Program Files\Google\Chrome\Application\chrome.exe` |
| Журнал | `memory\sessions_bill_review.md` в каталоге проекта Claude Code |

Структура архива: `<АРХИВ>\<год>\<магазин>\Чек_YYYY-MM-DD_<ID>.pdf`.

## Соответствия организация / ИНН → папка

Для отправителей, под чьим адресом приходят чеки от РАЗНЫХ организаций (1-ОФД
`echeck@1-ofd.ru`, Такском `noreply@taxcom.ru`, ОФД.ру `noreply@ofd.ru`,
ОФД-Яндекс `no-reply@ofd.yandex.ru`), папку выбирают по организации/ИНН из тела.
Веди здесь свою таблицу — дополняй по мере появления новых магазинов (механизм
автозаведения — §4 в `SKILL.md`). Формат папки — кириллица + подчёркивание.

| ИНН / организация | Папка | Отправитель |
|---|---|---|
| `<ИНН или название>` | `<Папка>` | `<отправитель>` |
| … | … | … |

> Отправители с фиксированной организацией (ofd-magnit → Магнит, beeline →
> Билайн, check.yandex → Яндекс.Маркет, litres → ЛитРес, Anthropic) в этой
> таблице не нужны — их папка задана в `references/providers.md`.

## Приватность

Если репозиторий публичный — не вписывай сюда реальный адрес почты, домашний
путь с именем пользователя и список своих магазинов. Держи реальные значения в
локальной копии (`configuration.local.md`, она в `.gitignore`), оставив в
публичной версии плейсхолдеры.
